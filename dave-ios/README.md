# 大卫照片 · 原生客户端

SwiftUI 客户端，支持 iPhone 与 iPad（iOS/iPadOS 16 及更高版本），连接现有 `dave-photo` Cloudflare Worker 与 Windows 电脑端。它不会替代或修改现有网页、Windows 程序或 Cloudflare 数据。

## 功能

- 查看连接状态、刷新窗口、读取或恢复微信小程序相册、读取喔图相册。
- 远程查看和操作电脑上的小程序窗口；选择人物、分类、照片，缩略图与大图预览。
- 将选中照片保存到电脑、照片图库，或通过系统分享面板存到文件及其他应用；可选择是否允许小尺寸预览。
- 将预览分批缓存在设备上，最多 128 MB，可取消和清理。
- 对接现有 LocalFace：连接密钥、刷新人物、筛选、复核、导出与向 LocalFace 网页交接。

电脑端需要开机联网并运行工作台；微信相册读取依赖电脑上的微信小程序。照片内容可能是预览或带水印文件，程序不会声称是原片。LocalFace 网页交接会打开外部浏览器继续操作。

## 隐私和安全

当前 Cloudflare 远程入口按原有配置公开访问：知道网址的人可能操作连接中的电脑端工作台。客户端没有改变这项设置。设备缓存仅保存在 iOS 缓存目录，可在设置清理。没有将 LocalFace 密钥写入应用源码。

## 构建及测试

GitHub Actions 使用 XcodeGen 和 Xcode 打包未签名 IPA；安装前需要适当签名。调试版本可以用 `--mock-fixture` 参数运行合成相册，不连接真实云端；自动化界面测试仅使用该数据。真实连接协议应通过只读查询验证，避免改变用户当前相册状态。
